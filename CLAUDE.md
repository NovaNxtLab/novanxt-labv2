## Next.js version warning

This project runs **Next.js 16.4** (React 19.3), which has breaking changes relative to older Next.js versions in training data — APIs, conventions, and file structure may differ. Before writing Next.js code, read the relevant guide in the bundled docs at `node_modules/next/dist/docs/` (`01-app/` for App Router: getting-started, guides, api-reference) and heed deprecation notices. `AGENTS.md` is auto-regenerated by `next dev`; commit it rather than removing it.

## Commands

Package manager is **pnpm** (pinned via `packageManager`).

- `pnpm dev` — dev server on http://localhost:3000 (Turbopack)
- `pnpm build` — production build (also the main type-check gate)
- `pnpm start` — serve the production build
- `pnpm lint` — ESLint (flat config, `eslint-config-next` core-web-vitals + typescript)
- `pnpm exec tsc --noEmit` — type-check only

There is no test framework configured.

## Architecture

Early-stage App Router project (currently near the `create-next-app` scaffold); all source lives under `src/app/`. Import alias `@/*` → `./src/*`.

Key non-default config in `next.config.ts` that affects how code must be written:

- **`cacheComponents: true`** — Cache Components model is on. Dynamic data access must be wrapped in `<Suspense>` or cached with `"use cache"`; the older route-segment caching options (`export const dynamic`, `revalidate`, etc.) don't apply. See `01-app/01-getting-started/08-caching.md` and `09-revalidating.md` in the bundled docs.
- **`partialPrefetching: true`** — see `01-app/02-guides/adopting-partial-prefetching.md`.
- **`experimental.agentFeedback: true`**.
- **Tailwind CSS v4** is wired through a Turbopack rule (`@tailwindcss/turbopack` loader on `*.css`), not PostCSS. Theme tokens are defined CSS-first in `src/app/globals.css` (`@import "tailwindcss"` + `@theme inline`); there is no `tailwind.config.js`.

Layouts/pages use the global typed route props (e.g. `LayoutProps<"/">`) generated by Next rather than hand-written prop types. Fonts are Geist / Geist Mono via `next/font/google`, exposed as CSS variables.

Animation libraries available: `gsap` and `motion` (Motion, formerly Framer Motion). Both require Client Components (`"use client"`).
